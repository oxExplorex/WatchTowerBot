# Офлайн-просмотрщик WatchTower

В боте откройте «Настройки → Бекапы переписок → Скачать просмотрщик · Windows».
Распакуйте скачанный `WatchTowerViewer-windows-x64.zip` и запустите `WatchTowerViewer.exe`.
Устанавливать Python или сам бот не требуется. Можно перетащить бекап ZIP или `.wtb` на EXE.

Для запуска из исходников используйте `view_archive.bat` из корня проекта либо:

```console
python -m archive_viewer
python -m archive_viewer "путь/к/бекапу.zip"
```

Для исходников нужен Python с установленной зависимостью проекта `cryptography`.
Бот, PostgreSQL, `.env` и интернет для просмотра не нужны в обоих вариантах.

Выберите ZIP или любую часть `.wtb`; остальные части должны лежать рядом. В открывшемся браузере введите личный секрет. Слева — чаты от свежих к старым и поиск по названию, ID и аккаунту. Справа — сообщения по дням, фото, видео, круглые видеосообщения, GIF-анимации, голосовые, аудио и стикеры WebP/WebM/TGS. Картинки, видео и аудио, присланные документом, тоже получают встроенный просмотр. Воспроизведение зависит от поддержки кодека браузером; оригинал можно скачать. Кнопка `⋯` и ПКМ открывают версии сообщения. Даты отправки, редактирования и сохранения ботом подписаны отдельно, в часовом поясе компьютера. Если исходный текст не был получен, история прямо сообщает об этом. Отметка недоступности при проверке отличается от подтверждённого удаления.

После обновления вкладки откройте заново ссылку из окна просмотрщика: токен доступа хранится только в памяти вкладки.

Интерфейс разделён на навигацию, переписку и сворачиваемый инспектор. Доступны поиск
внутри выбранного диалога, календарь доступных дат, участники, галерея с догрузкой,
счётчики сообщений, сохранённых версий и вложений. Слова и ссылки
в инспекторе считаются по последним 500 сообщениям, чтобы не блокировать большой архив.
Кнопка «К дате» открывает только дни с сохранёнными сообщениями и переходит к первому
сообщению выбранного дня. При смене чата поиск сбрасывается. Фото, анимации и стикеры
открываются нажатием; сохранение оригинала доступно в шапке окна вложения.
Сохранённые версии включают первоначальное содержимое и последующие снимки сообщения.

Интерфейс обслуживается только на `127.0.0.1` со случайным портом и токеном доступа. Секрет передаётся локальному процессу на вашем ПК и не сохраняется. Внешних скриптов, CDN и запросов к Telegram нет. Расшифрованные вложения существуют в памяти; кнопка скачивания явно сохраняет выбранный файл. Временные файлы содержат только шифротекст и удаляются при завершении. Кнопка «Выйти» завершает приложение и закрывает архив. После закрытия последней вкладки
процесс автоматически завершается примерно за 15–20 секунд; задержка позволяет обновить
страницу или переподключить вкладку. Открытые фоновые вкладки удерживают процесс. Если
браузер вообще не подключился, приложение завершится через три минуты. «Заблокировать»
закрывает архив, сохраняя окно приложения; Ctrl+C в консоли также завершает просмотрщик.

Аватарки сохраняются при обходе диалогов и обновляются при фоновой обработке 10 чатов.
Вся доступная Telegram история фото добавляется в очередь порциями: прогресс хранится
в БД, уже известные фотографии повторно не добавляются. Скачивание проходит с общими
паузами Telegram; предыдущие фото не подменяют текущее. Публичный метод Kurigram
не имеет offset, поэтому при продолжении может повторно читаться часть метаданных.
Фотографии шифруются личным ключом. Смена или исчезновение фото не удаляет предыдущие
изображения: они доступны через «Аватарки · история» и входят в новые дампы. Повторное
появление того же фото после исчезновения — отдельная запись; байты могут использоваться
повторно. Если текущая фотография больше не видна, список чатов показывает инициалы.
Даты в истории — время наблюдения ботом, а не гарантированное время изменения профиля.
Изменения во время простоя и старые фото, которые бот не получил, восстановить из дампа нельзя.
Дампы с историей аватарок требуют просмотрщик 2.0.28 или новее; старые дампы открываются.

Видеоплитки показывают первый кадр и длительность; превью загружаются по мере появления
на экране. Поддержка видео зависит от кодеков браузера. Блок ссылок и частых слов свёрнут
по умолчанию; карточки ссылок строятся из сохранённых данных без обращения к сайтам.

Новые сообщения сохраняются только из личных переписок с людьми. Боты, группы
любого размера, супергруппы, каналы и чат Telegram `777000` исключены до записи.
При обновлении ранее сохранённые данные групп, каналов, подтверждённых ботов
и чата `777000` удаляются из БД, а неиспользуемые файлы — через очередь очистки.
Типы старых положительных ID проверяются через Telegram небольшими порциями;
неопознанные записи сохраняются до подтверждения типа. Уже скачанные и отправленные
бекапы это не изменяет. Ограничения чатов применяются при сохранении данных;
при выгрузке сохранённые сообщения дополнительно не скрываются.

В панели статистики показаны чаты, сообщения, сохранённые версии, прогресс проверки
истории и вложения. Файловый объём учитывает реальные размеры зашифрованных файлов
без дублей, включая аватарки. Общий объём — содержимое записей и файлы; служебные
таблицы, индексы PostgreSQL и уже отправленные бекапы в него не входят.

Доступно только содержимое, которое бот успел сохранить. Проверка целостности всего
бекапа выполняется до показа переписок. Для больших архивов она может занять время;
поддерживается до 256 МБ метаданных и 128 МБ расшифрованных данных одного вложения.

## Обновления EXE

Внизу левой панели показаны версия приложения, номер сборки и результат проверки.
«Проверить обновление» повторяет проверку; при наличии новой сборки появляется «Обновить».
Перед установкой архив блокируется, затем приложение перезапускается. Для запуска
из исходников отображается отдельный статус: автообновление исходников не выполняется.

При запуске Windows EXE проверяет опубликованную сборку на GitHub, до открытия архива
и ввода секрета. Новая версия скачивается, проверяется по SHA-256 и самопроверкой EXE,
затем заменяет установленную и перезапускается. Рядом остаётся резервный `.exe.previous`.
Если обновление недоступно, запускается установленная версия; доступен флаг `--no-update`.
Исходники автоматически не изменяются. Бекап, путь к нему и секрет на GitHub не отправляются.

Старую сборку, в которой ещё нет механизма обновления, нужно один раз заменить вручную.
Последующие обновления она получит автоматически. Доверие к обновлениям основано на HTTPS
и контроле репозитория публикации; отдельной цифровой подписи EXE пока нет.

Каждая попытка установки использует отдельный временный каталог; новый EXE не переименовывается
сразу после самопроверки. Каталоги загрузок старше семи дней очищаются при следующем обновлении.
При отказе выводятся этап и код ошибки Windows. Если установленная сборка не может обновиться,
после публикации новой сборки замените её вручную из ZIP просмотрщика.

## Файлы медиа `.wtm`

WTM — контейнер проекта, а не новый алгоритм шифрования. В текущем формате WTM2
содержимое защищено AES-256-GCM со случайным ключом каждого файла. Этот ключ
зашифрован RSA-OAEP-SHA256 открытым ключом владельца; закрытый ключ хранится
зашифрованным и открывается личным секретом через Argon2id (64 МиБ, 3 прохода).
Новые вложения перед шифрованием проверяются по образцу: если сжатие выгодно,
используется zlib без потерь. Фото, видео и аудио не перекодируются. При открытии
восстанавливаются исходные байты, включая метаданные файла.

Переименование файла или снятие проверки пароля не расшифровывает содержимое.
Слабый секрет можно подбирать при наличии зашифрованного закрытого ключа из БД
или бекапа. Размеры файлов и служебный заголовок не скрыты. Открытый просмотрщик,
его память и ввод секрета требуют доверенного компьютера.

Старый WTM1 использует серверный ключ, без личного секрета. Расширение у обеих
версий одинаковое; версия записана в первых четырёх байтах. Сам файл WTM2
не содержит закрытого RSA-ключа: для переносимого просмотра сохраняйте полный
бекап ZIP/WTB, в котором есть и зашифрованный набор ключей.

## Сжатие без потерь

Сжимаются новые тексты сообщений, метаданные бекапа и подходящие вложения — до
шифрования. Уже зашифрованные данные почти не сжимаются, поэтому ZIP служит контейнером
для частей бекапа. Текст и несжатые документы обычно уменьшаются заметнее, чем JPEG,
WebP, MP4 и другие уже сжатые форматы. Уменьшение любого архива в несколько раз
не гарантируется. Дубли вложений по-прежнему используют один сохранённый файл.

Существующие зашифрованные записи и файлы автоматически не перепаковываются.
Для перепаковки личного содержимого нужен секрет владельца; серверного ключа
недостаточно. Для новых сжатых бекапов нужен просмотрщик 2.0.28 или новее.
Новый просмотрщик продолжает читать старые бекапы и файлы WTM.

## Сборка и распространение

Workflow `Build archive viewer` собирает Windows x64 EXE после push изменений просмотрщика в `main`
или ручного запуска через GitHub Actions. Файл публикуется как asset релиза `archive-viewer`;
кнопка бота ведёт на его постоянный URL. До первой успешной публикации файл по ссылке отсутствует.
Сборка не читает секреты бота и не включает `.env`, БД или пользовательские архивы.

Для локальной сборки создайте отдельное окружение Python на Windows и установите
`archive_viewer/requirements-build.txt`, затем выполните `python scripts/build_archive_viewer.py`.
ZIP и SHA-256 появятся в `dist/archive-viewer/` (исключён из Git).
Перед упаковкой собранный EXE сам проверяет криптографию, тестовый архив и наличие HTML/CSS/JS
из временной папки за пределами репозитория. Сборщик не запускается на сервере бота и не входит
в его зависимости. Используется [PyInstaller](https://pyinstaller.org/en/stable/),
ресурсы упакованы [относительно модуля](https://pyinstaller.org/en/stable/runtime-information.html#placing-data-files-at-expected-locations-inside-the-bundle).

Для TGS встроен `lottie-web` 5.13.0, Canvas Light без поддержки выражений и внешнего CDN.
Источник: [airbnb/lottie-web, commit bede03d](https://github.com/airbnb/lottie-web/tree/bede03d25d232826e0c9dca1733d542d8a7754fb), MIT.
SHA-256 `lottie_light_canvas.min.js`: `0930bfecb5b5dad59dd9049a139fa957e57f70e0805fc94a311204e524e45e28`.
Лицензия находится в `assets/lottie-LICENSE.md` и в ZIP программы.
